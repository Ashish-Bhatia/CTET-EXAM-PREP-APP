## Governing source rules

Only binaries directly exposed by the official CTET website are eligible for this manifest. No third-party mirrors, coaching sites, cached files, Telegram files, YouTube files or unofficial copies are admitted.

The required binary lifecycle is:

`OFFICIAL_PAGE_ONLY -> BINARY_ACQUIRED -> HASHED -> ZIP_VALIDATED -> OFFICIAL_BINARY_VERIFIED -> EXTRACTED -> INVENTORIED -> READY_FOR_ANALYSIS`

No hash, local acquisition filename, ZIP validation result, extraction result or verification claim is recorded before actual binary bytes enter the controlled environment.
